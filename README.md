# 세계 수도 퀴즈 (Capital Quiz)

나라 이름을 보고 수도를 맞히는 웹 퀴즈입니다. UN 회원국 193개국을 수록했고,
한국어를 기본으로 하되 영어 표기를 함께 보여 줍니다.

**▶ [바로 플레이하기](https://ctbot000.github.io/capital-quiz/)**

## 기능

- **지역 선택** — 전체 / 아시아 / 유럽 / 아프리카 / 북아메리카 / 남아메리카 / 오세아니아
- **문항 수 선택** — 10 / 20 / 50 / 전체
- **두 가지 방식**
  - 객관식: 4지선다, 키보드 `1`~`4`로도 선택 가능
  - 주관식: 한글 또는 영어로 직접 입력 (띄어쓰기·대소문자·구두점 무시)
- **즉시 채점 & 해설** — 문제마다 정답을 바로 확인
- **결과 리뷰** — 틀린 문제 목록과 "틀린 문제만 다시 풀기"
- **최고 기록 저장** — 설정별 최고 정답률을 브라우저에 저장 (localStorage)
- 다크 모드 및 모바일 화면 지원

## 실행 방법

빌드 도구나 의존성이 없는 정적 사이트입니다. 저장소를 받아 로컬 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. `index.html` 파일을 직접 열어도 동작합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (시작 / 퀴즈 / 결과) |
| `styles.css` | 스타일, 라이트·다크 테마 |
| `data.js` | 193개국 국가명·수도 데이터 |
| `app.js` | 퀴즈 로직 |

## 데이터에 관하여

- UN 회원국 193개국을 기준으로 했습니다.
- 수도가 여러 개이거나 논쟁이 있는 나라는 대표 표기를 정답으로 두고,
  주관식 모드에서는 `alt` 필드의 다른 표기도 정답으로 인정합니다.
  (예: 볼리비아 → 수크레 / 라파스, 남아프리카공화국 → 프리토리아 / 케이프타운 / 블룸폰테인)
